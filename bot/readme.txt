Внимание! Треуется обновить авторизационные данные в файле ENV.

Требуется аутентификация сторонних сервисов:
1 my.telegram.org (при первом запуске требуется подтверждение телефонного номера через ssh или в python скрипте)
2 любой поставщик proxy с аутентификацией
3 twitter - логин и пароль аккаунта

Конфигурация: 
требуется заполнить путь к папке бота 
path_to_bot
и сконфигурировать базу даных
database

Также требуется актуальный chromedriver
