Задача
Требуется вывести на UI форму ввода, в ней 3 поля
текстовое поле login
текстовое поле order number
селектор со строкой поиска и выпадающим списком и чекбоксами для выбора пунктов из этого списка.

Поле Login заполняется текущим имененм пользователя (но может быть отредактировано)
Поле текстовое поле order number пустое, но может быть отредактировано 
Поле селектора состоит из перечня для выбора, где option value это id, а текстовое поле это description из таблицы каталога "products". При вводе символов в поле поиска из селектора должны быть отфильтрованы только те что содержат введенные символы. При выборе одного из чекбоксов добавлять его в формате tag над полем селекта, добавить возможность удалить этот tag, но про удалении снимать и соответствующий ему checkbox. 

Далее разместить кнопки search и submit, если поле order number заполнено, то кнопка search активна, если поле order number пусто, кнопка search заблокирована. кнопка Submit активна только еслли выделен хотя бы один чекбокс.

При нажатии кнопки Search на api-gateway отправляется запрос get /api/test/search/{order_id}
при получении ответа требуется заполнить поле login и отметить checkbox соответствующие перечисленным в ответе id.  

При нажатии кнопки Search на api-gateway отправляется запрос post /api/test/submit
отправляются поля login и список отмеченных id checkbox соответствующих селекторов.  

Требуется также скорректировать api-gateway и перенаправлять запросы get /api/test/search/{order_id} и post /api/test/submit на сервис selectcb get /test/search/ и post /test/submit
ограничить запросы не более 2 в минуту, проверить что токен пользователя еще действует

Реализовать сервис selectcb, использовать ту же базу данных  DATABASE_URL: str = 'dbname=db_bot user=postgres password=1qaz!QAZ host=host.docker.internal'
запросы
get /test/search/
по переданному order_id предоставить в ответ order_id, login и список product_id 
post /test/submit
внести переданные значения в таблицы

Таблицы
Таблица products состоит из полей product_id и product_description.
В таблице orders  поля order_id, login 
В таблице orderdetails поля order_id, product_id
