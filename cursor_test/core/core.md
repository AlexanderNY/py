Требуется создать сервис авторизации со следующим функционалом 
1. Проверка Healthcheck все сервисов
        запрос get /healthchecks на сервис core
        запрос запускает последовательно опрос всех сервисов (запрос к каждому сервису /healthcheck но через API Gateway)
2. Проверка статистики работы сервиса
        запрос get /statistics на сервис core
        запрос запускает последовательно опрос всех баз данных и таблиц для сбора информации о том сколько постов собрано и опубликовано кадым из ботов
